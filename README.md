\# Auto Sales Customer Segmentation



An end-to-end machine learning project for customer segmentation using RFM analysis and KMeans clustering.



\## Technologies Used



\- Python

\- FastAPI

\- Pandas

\- NumPy

\- Scikit-learn

\- KMeans Clustering

\- Joblib

\- HTML

\- CSS

\- JavaScript

\- Chart.js



\## Features



\- Customer segmentation using RFM analysis

\- KMeans clustering

\- Country filtering

\- Product line filtering

\- Sales analysis

\- Customer lookup

\- Cluster profiles

\- Customer cluster prediction

\- Interactive dashboard

\- FastAPI REST API
